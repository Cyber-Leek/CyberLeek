# Network Security Knowledge Base

This folder contains security knowledge used by the Explainable Network IDS.

## Purpose

The Knowledge Base provides additional context about detected threats.

It can contain:

- Attack types
- Attack descriptions
- Common indicators
- Recommended investigation actions
- Security terminology
- MITRE ATT&CK references

## Usage

The backend/AI layer can use this information to enrich machine-learning
predictions with human-readable security context.
